How to Quickly Prefix Object & Room Names in Quest .aslx Files

Goal

Avoid manual renaming of 600+ objects/rooms in a Quest game file by automatically adding prefixes (like f_ for Fishvale or s_ for Sekiro) to all <object> and <room> names.

Step-by-Step in Notepad++

1. Open Notepad++
Open your .aslx game file.

2. Open Replace Tool
Press Ctrl + H to open the Find and Replace panel.

3. Settings
Find what: <(object|room) name="([^"]+)">
Replace with: <\1 name="f_\2"> (Replace f_ with any prefix you need)
Search Mode: Regular expression
Don’t check: “Extended” or “Normal”

4. Click "Replace All"
Done! All object and room names are now safely prefixed.

Example

Before:

<object name="cat">
<room name="tower">

After:

<object name="f_cat">
<room name="f_tower">

Pro Tips

  • Repeat for Sekiro objects with s_
  • Do not touch:
    • <inherit name="..." />
    • <attr name="..." />
  • They are not real objects and will break if renamed.

Why This Works

  • No manual renaming
  • No JavaScript or scripting
  • Compatible with all Quest tools
  • Works instantly even for huge files
